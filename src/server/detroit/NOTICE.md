# Detroit AI Player attribution

The decision-tree data in `data/zh/` is adapted from
[Detroit AI Player](https://github.com/Baba88611/detroit-ai-player) by Joey Zhang,
repository commit `86bc84c48b06ca2a5fd5ab1ffd3789345ceb9e15`.

The data is licensed under CC BY-NC 4.0. Lumbre adds a TypeScript step runner and
persistent main-chat tool integration; it does not include assets from the original
game. The runner behavior was adapted from the upstream MIT-licensed Python code.
License texts are retained in `licenses/`.
