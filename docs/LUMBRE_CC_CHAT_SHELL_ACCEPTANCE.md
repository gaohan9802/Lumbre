# Claude Code 双线路外壳：阶段 1 验收记录

日期：2026-09-05。分支：`codex/lumbre-cc-chat-shell`。开工基线：`4e8b921`。

结论：阶段 1 已在本地完成并通过自动化与响应式检查，尚未推送、部署或接入真实 Claude Code。进入阶段 2 前仍需用户完成分支预览确认。

## 1. 本阶段实际完成

- 新增 `api | claude-code` 高层线路类型；旧会话、旧消息和旧回复版本升级后按 API 处理。
- 会话保存下一轮默认线路与独立更新时间；消息、自动唤醒消息和回复版本保存实际线路。
- 线路字段已覆盖浏览器迁移、消息版本快照、续窗、对话分支、离线待发箱、增量同步、服务端 manifest 与持久 session 合并。
- 较旧设备上传更新后的聊天内容时，不会抹掉另一台设备上较新的线路选择。
- Chat 输入区上方显示真实 `API · 渠道 · 模型`；点击打开重构后的“发送线路与模型”底部面板。
- 当前面板只显示真正可用的 API 模型。CC 没有假按钮，额度和上下文没有假数字。
- 助手消息元数据显示实际线路与模型，为未来同一窗口混用 API/CC 保留辨识依据。
- 浏览器请求明确带 `generation_route: api`；当前 API endpoint 对任何非 API 线路返回 409，不做静默降级。
- 抽出 `ChatRoutePicker`，移除 `ChatView` 内原有整块模型选择面板代码，没有改变摘要、书签、图片、Timeline、长短聊和工具循环。
