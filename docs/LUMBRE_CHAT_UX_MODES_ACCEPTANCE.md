# Lumbre 聊天页面整理与长短模式验收记录

日期：2026-09-05

分支：`codex/chat-ux-voice-modes`

基线：`main` / `4c54301cfa6b01750886d763c8c5a911c524e4d1`

## 已完成

- 聊天页输入区收成输入、加号、发送；图片、Timeline 和长聊/短聊放在加号展开区。
- 摘要、书签、券包、模型、星星、设置、壁纸统一进入右侧菜单；换窗固定在菜单底部。
- 星星人设默认只读，点击“编辑”后才出现草稿；保存、取消、遮罩、返回和关闭都处理未保存修改，保存时检查并发版本。
- 壁纸面板提供日间/夜间独立的气泡颜色、透明度、磨砂开关和 0–20 px 强度拉杆，并用于历史和流式气泡。
- 长聊/短聊按会话保存并同步；换窗继承模式。请求、消息和版本记录发送时的模式，重生成沿用原模式。
- 短聊使用模型指令生成短句，并用独占行 `<!--split-->` 将一轮回复显示成多个气泡；正文仍是一条消息，不增加消息轮数。代码块、链接、思考块和工具块不会被错误拆分。
- 语音录音、转写、声学分析和麦克风按钮按用户决定取消，使用苹果键盘听写。

## 限制与回退

本轮没有接入真实模型凭据，也没有声称真实模型输出或实体 iPhone/PWA 已验收；服务端测试使用无网络的 provider stub。分支尚未合并 `main`，也没有触发生产部署，待用户预览确认。

新增模式和外观字段都是可选字段，旧数据缺失时分别回到长聊和现有外观；回退代码即可恢复，不能通过清空聊天数据解决问题。
